# course-info — sample private documents

These files stand in for **your own private notes** that live only on your laptop.
They describe a few made-up courses: the room, the meeting time, the instructor,
office hours and exam details. The names and emails are fictional.

In Part 11 of the lab, your agent reads these files to answer questions like
"What room is my psychology class in?" — information the AI model has no way of
knowing on its own, because it only exists here, on your machine.

## Make it yours

Open any file in a plain-text editor and change it, or add a new file for one of
your real courses (copy the layout of an existing file). Start a new chat and ask
your agent again.

## ⚠️ Keep real private notes out of GitHub

This repository is **public** if you publish it. These sample files are safe
because they're invented. If you put your *real* schedule, address, or anything
private in this folder, **don't commit and push it** — add `course-info/` to your
`.gitignore` first, or keep your real notes in a folder outside the repository and
point your agent there instead.
